# Projeto Padawan

## Descrição
Ferramenta de Simulação de Investimentos onde é possível simular quais os ganhos em determinado período, aplicado a uma taxa de rendimento. 

## Tecnologias utilizadas
- Excel

## Como executar
Inserir o patrimônio a ser investido e a quantidade de tempo que deseja investir o montante.
